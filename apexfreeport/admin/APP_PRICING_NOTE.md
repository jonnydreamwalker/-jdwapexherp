# Wholesale pricing rule

- The number you type in **Wholesale price ($)** is the exact lot price dealers pay.
- There is **no** auto discount (no 15%, no 0.85).
- **$/lb** = wholesale price ÷ weight (lb).
- If Wholesale $ is blank and WHOLESALE is checked, List Price is used as the wholesale total (exact).
- Re-save each bulk SKU once after updating so inventory stores the correct dealerPrice.
